# 0.673 and lift the production field's own pixel AUC 0.884 -> 0.911. The selector

# is where the information is, and only the network can use it there.

# Same recipe as the baseline in every respect except --channels mag: the raw image
# keeps its slot, channel 2 is the smoothed signed field (+/-50 G, polarity is the
# information), channel 3 is log distance to the nearest polarity inversion line.

# seasons) is in-distribution. Judged at matched member count on folds 0 and 1,
# exactly as E156b judged resolution.
